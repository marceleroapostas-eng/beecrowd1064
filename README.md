# Beecrowd 1064 - Positivos e Média

## Descrição

Este programa resolve o problema 1064 do Beecrowd, que consiste em ler 6 valores, identificar quantos são positivos e calcular a média dos valores positivos.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

O programa recebe 6 valores, que podem ser números inteiros ou de ponto flutuante.

## Saída

O programa deve imprimir a quantidade de valores positivos e, na linha seguinte, a média dos valores positivos com uma casa decimal.
